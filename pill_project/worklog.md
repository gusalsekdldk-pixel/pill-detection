# 업무일지 - 2026-10-23

## 오늘의 목표
제공 데이터로 알약 검출 모델을 학습하고 Kaggle 제출까지 완료한다. 시간 제약에 맞춰 기본 모델 1개를 사용한다.

## 실제 수행 내용
- Google Drive에 데이터를 업로드하고 Colab T4 GPU 환경을 연결했다.
- 최초 경로 오류를 실제 `코드잇` 하위 경로로 수정했다. 업로드 도중에는 이미지 수가 0개로 표시되어 완료 후 재확인했다.
- 이미지 232장과 JSON 763개를 확인했다. 같은 이미지에 해당하는 알약별 주석을 합쳤고, 56개 클래스를 확인했다.
- 이미지 누락과 정답 누락 및 JSON 파싱 오류는 0건이었다. 이미지별 객체 수는 4개 74장, 3개 151장, 2개 7장이었다.
- 좌표 검사 과정에서 잘못된 박스 1개를 제외하고 COCO 박스를 YOLO 형식으로 변환했다.
- seed 42로 186장 학습 / 46장 검증으로 나눠 YOLOv8n을 15 epochs 학습했다.
- best.pt 내부 검증에서 Precision 0.767, Recall 0.590, mAP@50 0.742, mAP@50-95 0.711을 확인했다.
- 테스트 287장에 대해 1,148개 객체를 예측했다. 원본 category_id로 복원해 submission.csv를 생성하고 Kaggle에 제출했다. 확인한 점수는 0.10093이다.

## 문제와 판단
폴더별 개별 파일 업로드에 시간이 걸렸다. 다음에는 압축파일을 활용하는 방안을 고려한다. results.csv는 학습 기록이며 Kaggle 제출 파일이 아니라는 점을 구분했다. 내부 검증 점수와 Kaggle 점수는 평가 기준 및 데이터가 달라 직접 비교할 수 없다. 유사 이미지가 분할 양쪽에 포함되었을 가능성도 있어 내부 결과만으로 일반화 성능을 판단하지 않는다.
